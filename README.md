# ticker — 終端機行情面板

在 Windows Terminal 裡跑的即時行情面板：上方看台股、美股、日韓、總經與類股，右側看選中個股或大盤的日 K、均線與型態判讀，下方留給 Claude Code。配色取自 TradingView 深色主題。

## 功能

**報價**
- 多頁籤：庫存、觀察、台股、美股、日韓、總經、類股；依窗格高度自動分頁，每 20 秒自動翻頁。
- 台股、加權指數走證交所 MIS，台指期、電子期走期交所，獨立 5 秒迴圈，不跟國際報價排隊。
- 設了富果 API key 時，選中的那一檔改用富果 WebSocket 逐筆推播（免費方案一次一檔）；富果沒推時 MIS 接手。
- 國際報價走 Yahoo（約 15 秒一輪），被限流時改抓 CNBC 補上對得到代號的部分。
- 收盤的市場跳過不抓，夜裡請求量大幅減少。
- 盤中超過 90 秒沒拿到新報價的列整列變暗，一眼看出哪一檔斷線。

**表格欄位**
- 多空比（台股盤中）：外盤對內盤的比例，左紅右綠。選中那一檔用富果的真實內外盤，其他用 MIS 5 秒快照推估；累計值每 30 秒存進 `flow.json`，重開面板接著算。收盤、休盤與其他市場這一欄顯示今日區間條（依價量上漸層色）。
- 量比（爆量亮黃字、量縮變暗）。
- 乖離：現價對 20 日均線，超過 ±8% 標追高（橘字）／回檔（藍字）。
- 年區間：現價在 52 週高低點的位置。
- 外資：證交所 T86 外資連續買賣超天數（上市股）。
- 型態：自動判讀最重要的一條（見下方）。
- 買點：兩顆燈，同步閃爍。
  - 左燈（橘）：現價在半年線上方 5%～10%。
  - 右燈（紅）：季線上揚、拉回月線或季線 2% 內又收回、最近三天量低於月均量、出現長下影線／多頭吞噬／站回月線，四項全成立。
- 庫存頁的漲跌、幅度改成今日損益與總報酬。
- 報價跳動時價格格閃一下；換頁用翻牌動畫（手動換頁快三倍）。
- 窗格太窄時照順序藏欄位（型態 → 年區間 → 外資 → 乖離 → 今日區間 → 量比），名稱、代號、價格、漲跌、幅度、買點永遠留著。
- 選中那一列暗藍底、名稱前一條亮藍線；表格隔列亮一階（斑馬紋）。

**右側 K 線面板**
- 選中個股的日 K（存最近 250 根），K 棒顏色代表站在哪條均線上：亮紅站上季線、暗紅只站上月線、綠色跌破月線。
- 月線（紫）、季線（藍）、半年線（橘）用點線畫在 K 棒之間；資料不滿該天數的不畫。
- K 線下方兩行成交量柱，收紅紅柱、收黑綠柱，今天那根用盤中累計量。
- 今天那根用即時報價組成，盤中跟著跳，不用等盤後。
- 下方置中列出 5 日、月線、季線、半年線、區間高低，以及最多兩行說明：買點燈亮時第一行寫出成立的條件（例如「季線上揚・回測季線・量縮・長下影」），其餘是型態白話說明。
- 點上方大盤列的任一指數，K 線改看該指數；台指期、電子期沒有日線，會顯示提示。
- 視窗太窄時自動收起。

**型態判讀**（用已收盤的日 K，少見的優先列）

| 類別 | 型態 |
|---|---|
| K 棒 | 多頭吞噬、空頭吞噬、十字線、長下影線、長上影線 |
| 位置 | 突破月高、跌破月低、回測月線 |
| 趨勢 | 多頭排列、空頭排列 |

**畫面**
- TradingView 深色配色：深藍灰底，表格與 K 線各一層面板底色，紅漲綠跌降低飽和度，長時間盯盤不刺眼。
- 底部快捷鍵列（Bloomberg 風格），空白鍵的說明跟著暫停狀態換。
- 每幀只重寫有變動的行（平常約 1.4KB），每 10 秒整頁重畫一次防止畫面走樣。
- 報價整批寫入：Yahoo 一輪、MIS 一輪都抓完才一起寫，寫入與組畫面互斥，同一頁在同一幀一起跳。
- 點擊、按鍵進來立刻處理，不等下一幀；滑鼠序列收完整才解析，不會被誤判成換頁鍵。
- 調整垃圾回收，避免完整回收剛好落在某一幀造成卡頓。

**其他**
- 底部跑馬燈：異動排行、警示訊息，左側固定 DXY、Brent、黃金、VIX、美債 10Y。
- 警示：`portfolio.json` 的「警示」設到價上下限，另有爆量警示，每條每天只響一次。
- 觀察清單可依產業分組，組名當成一列標題。
- 單一實例鎖（port 47653），不會重複開出兩個面板。

## 操作

| 按鍵 | 動作 |
|---|---|
| 點個股列、`↑` `↓` | 選中該檔，右側 K 線跟著換，並暫停自動翻頁 |
| 點大盤列 | 右側 K 線改看該指數，並暫停自動翻頁 |
| `←` `→`、滑鼠滾輪 | 上一頁／下一頁 |
| 數字鍵、點頁籤 | 跳到第幾個頁籤；再點同一頁籤翻它的下一子頁 |
| `+` `-` | K 線縮放（三段） |
| 空白鍵 | 暫停／恢復自動翻頁（標題出現 ⏸） |
| `q` | 離開 |

底部快捷鍵列隨時列出這些按鍵。

## 安裝

```
git clone https://github.com/Devchou012/ticker.git %USERPROFILE%\ticker
python %USERPROFILE%\ticker\install.py
```

`install.py` 可以重複跑，已完成的步驟會跳過：
1. 安裝 `rich`、`yfinance`。
2. 從 `portfolio.example.json` 建立 `portfolio.json`（不進 git，各台機器自己一份）。
3. 加 Claude Code SessionStart hook：在 Windows Terminal 開 Claude Code 時自動在上方分割出面板。
4. 在 PowerShell profile 加 `cs`（別名 `股票介面`）指令。
5. 桌面建立「行情面板」捷徑。

**富果逐筆（選用）**

```
pip install fugle-marketdata
powershell -ExecutionPolicy Bypass -File "$HOME\ticker\set_fugle_key.ps1"
```

key 存成使用者環境變數 `FUGLE_API_KEY`，輸入時只顯示 `*`，不會進 git。沒設就用 MIS 5 秒快照；選中那一檔的多空比也改用推估值。

## 管理清單

```
python watch.py 興富發 2881 NVDA   # 加入觀察（台股名稱或代號、美股代號）
python watch.py -d 興富發           # 移除
python watch.py                     # 列出
```

面板一秒內會讀到變更。庫存（股數、成本）與警示直接改 `portfolio.json`，格式見 `portfolio.example.json`。

## 可調參數

在 `ticker.py` 開頭附近，改完存檔面板會自動重開：

| 常數 | 預設 | 用途 |
|---|---|---|
| `ZONE_LO`、`ZONE_HI` | 1.05、1.10 | 橘燈的半年線區間 |
| `NEAR_MA` | 0.02 | 低點離均線多近算「回測」 |
| `FLASH_SEC` | 0.25 | 燈號閃爍半週期（秒） |
| `STALE_SEC` | 90 | 盤中多久沒新報價就變暗 |
| `FLIP_FAST` | 3 | 手動換頁的翻牌加速倍數 |
| `MA_GAP` | 5 | K 線下方均線列的項目間隔 |
| `BG`、`PANEL`、`ZEBRA` 等 | TradingView 色票 | 配色 |

## 已知限制

- 台股免費來源的極限是 MIS 5 秒快照；逐筆要富果（免費一次一檔）或券商 API（富邦 Neo API 需證券戶與憑證）。
- 多空比推估值：5 秒內的多筆成交只能整包歸同一邊；面板關著那段的量分不出內外盤，會直接略過。要完整一天的推估，面板要在 9:00 前打開。
- 交易時段寫死，不管國定假日與美股夏令時間，量比在這些時段會略偏；只有多空比會用 MIS 回的交易日判斷台股是否休市。
- 期交所日盤收盤（13:45）到夜盤開盤（15:00）之間剛開面板，台指期會暫時空白。
- 日線每天盤後抓一次；盤中只補抓清單裡缺的個股（每 10 分鐘最多一次）。
- 終端機畫不出圓角、陰影與列間細線：分區用面板底色、列與列用斑馬紋代替。燈號是 emoji，長相依字型而定。

## 規劃中：網頁版

終端機版維持主力（跟 Claude Code 同一個視窗，寫程式時一眼看得到）；網頁版當第二畫面，給深入看盤與手機用。兩者共用同一套資料與判斷，新功能只寫一次。

**為什麼要做**：終端機畫不出圓形光暈、列間細線，字型跟著 Windows Terminal 設定走，點擊要從畫面文字反推位置。網頁沒有這些限制，K 線還能縮放、拖曳、滑鼠停留看數值。

**做法**
1. 拆出資料層：報價、日線、多空比、買點與型態判斷從 `ticker.py` 拆成共用模組，終端機版改成呼叫它。
2. 本機服務：加一個小型 HTTP／WebSocket 服務，每秒推送報價與燈號；瀏覽器不能直接抓證交所、Yahoo（跨網域限制），資料一律由 Python 後端抓。
3. 前端：表格加 TradingView 的開源圖表庫 [lightweight-charts](https://github.com/tradingview/lightweight-charts) 畫 K 線、均線與量柱，配色沿用目前的 TradingView 色票。
4. 開放範圍：只聽本機或家中區域網路。要在外面用手機看，得先處理登入保護，富果金鑰與 `portfolio.json` 的庫存不能外露。

**代價**：要另外開瀏覽器視窗；兩套畫面都要維護（資料層共用可以減少大半）；對外開放需要額外的安全設計。

**先決定的事**：主要用途是寫程式時瞄行情（留在終端機即可），還是專門看盤、需要手機（值得做網頁版）。
